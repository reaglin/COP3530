Introduction

An array is the simplest and most fundamental data structure you will study in this course: a fixed-size block of memory holding elements of the same type, laid out one after another with no gaps. Because the elements are contiguous, the computer does not need to search for an element — it can compute exactly where element i lives using the address of the first element, the index, and the size of each element. That single idea, direct address calculation, is why array access is constant time and why arrays serve as the building block for so many other structures.

The details matter. Zero-based indexing is not an arbitrary convention; it falls out of the address formula, since the first element sits zero elements away from the base address. Fixed size and static allocation matter too: when an array is declared, the space is reserved up front, so growing it later usually means allocating a new, larger block and copying. And accessing an element by index is a completely different operation from searching for a value — one is a calculation, the other requires examining elements until you find a match.

As you watch, pay attention to three things: how the memory address of an element is computed, where in memory arrays actually live (stack versus heap, and who hands out that memory), and the distinction between knowing an index and having to look for a value. Keep a mental note of how these mechanics will later explain the Big O costs you will assign to array operations.
