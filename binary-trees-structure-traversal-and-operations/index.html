Binary Trees: Structure, Traversal, and Operations

This lesson introduces binary trees and binary search trees, covering node structure, insertion, deletion, and key traversal strategies including in-order, pre-order, and post-order. Students will implement a binary search tree in JavaScript and analyze its operations.

    Expression Arbor — Interactive Expression Tree & Traversal Practice

    Expression Arbor is a browser-based interactive exercise in which students build a binary expression tree from a given arithmetic expression by placing operator and operand tiles onto a growing tree structure. As the tree takes shape, the activity displays the resulting pre-order, in-order, and post-order 'walks' and scores each attempt against the correct traversal sequences. Color coding distinguishes operators, numbers, and parentheses, and a round map tracks progress, correctness, and points across multiple expression challenges.
