Introduction

So far in this module you have studied graphs on paper: vertices, edges, directed versus undirected relationships, and the trade-offs between adjacency matrices and adjacency lists. Now you will turn those ideas into working code. The goal of this topic is to build a reusable Graph class in JavaScript that stores its edges as an adjacency list (commonly a Map or object whose keys are vertices and whose values are arrays of neighbors), exposes a method for adding edges, and then supports traversal.

Traversal is where the structure earns its keep. Breadth-first search uses a queue and a visited set to explore a graph level by level, while depth-first search follows one path as far as it can before backtracking. DFS can be written two ways: recursively, where the JavaScript call stack does the bookkeeping for you, or iteratively, where you manage an explicit stack. Writing both versions makes the relationship between recursion and stacks concrete, and it prepares you to handle graphs large enough that deep recursion becomes risky.

The videos below walk through implementations of BFS, recursive DFS, and iterative DFS on an undirected graph. While watching, pay attention to three things: how the graph is represented and how edges get added for an undirected graph (both directions), where the visited set is checked and updated, and the exact order in which vertices are printed. Afterward, run the same graph through all three traversals yourself and compare the output orders so you can explain why they differ.
