Introduction

Breadth-First Search (BFS) is a graph traversal strategy that explores a graph in layers: starting from a source vertex, it visits every neighbor at distance one, then every vertex at distance two, and so on. The engine behind this level-by-level behavior is the queue, a first-in-first-out structure that holds vertices waiting to be explored. Alongside the queue you also need a visited set (or boolean array) so that cycles and shared neighbors do not cause a vertex to be processed twice.

BFS matters in this course because it is one of the two canonical traversals you will implement on top of your adjacency list representation, and because its level order gives it properties DFS does not have — most notably, in an unweighted graph BFS finds the shortest path in number of edges from the source. It also forces you to think about graphs that are not fully connected: a single BFS call only reaches the component containing the start vertex, so a complete traversal requires looping over all vertices and launching a new BFS from each unvisited one.

As you watch the videos below, focus on four things: exactly when a vertex is marked visited (on enqueue, not on dequeue, if you want to avoid duplicates), how the queue contents change at each step, how the traversal order depends on the order neighbors appear in the adjacency list, and where BFS shows up in practice — shortest paths, level/distance computation, web crawling, social network degrees of separation. Try tracing a small graph by hand before and after watching, and compare your order against the one in the video.
