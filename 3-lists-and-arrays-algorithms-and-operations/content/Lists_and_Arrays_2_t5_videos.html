Introduction

Traversal is the act of systematically visiting every element in a list or array so you can read, test, transform, or accumulate values. It is the foundation beneath almost every other array operation: searching, filtering, summing, copying, and rearranging all depend on some form of ordered visit to each element. In JavaScript you have several ways to express a traversal — a classic for loop with an index, a reverse loop counting down, a for...of loop over values, and higher-order methods such as forEach, map, filter, and reduce.

Each technique carries trade-offs. An index-based for loop gives you full control over the starting point, stopping condition, and step size, which is what you need for reverse traversal or for step-and-skip patterns like visiting every second element. A for...of loop is cleaner when you only need values and not positions. Higher-order methods are expressive and reduce boilerplate, but they hide the loop, so you still need to reason about what work is happening on each pass. Nested loops extend all of this to two-dimensional arrays, where an outer loop walks the rows and an inner loop walks the columns.

As you watch the videos below, pay attention to three things: which loop construct is used and why, how the index or iteration variable is controlled, and what the traversal costs in terms of how many elements are visited. Whenever a video shows a built-in method, try to picture the equivalent manual loop underneath it — being able to move between the two views is exactly the skill this module is building toward.
