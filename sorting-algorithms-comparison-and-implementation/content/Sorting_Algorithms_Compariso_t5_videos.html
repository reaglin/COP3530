Introduction

Quicksort is a divide-and-conquer sorting algorithm built around a single powerful idea: partitioning. You choose one element as the pivot, rearrange the array so that everything smaller sits to the pivot's left and everything larger sits to its right, and then recursively sort the two sides. Unlike merge sort, the combining step is free — once both halves are sorted in place, the whole array is sorted.

This topic matters because quicksort is the algorithm most language runtimes reach for in practice. Its average-case running time is O(n log n) with small constant factors and no large auxiliary array, but a poor pivot choice on already-sorted or adversarial input degrades it to O(n^2). Understanding why that happens — and how pivot strategies such as median-of-three or randomization push you back toward the average case — is exactly the kind of reasoning this module asks you to do.

As you watch, keep three questions in front of you. First, trace the partition loop carefully: which pointers move, when do swaps happen, and where does the pivot finally land? Second, notice how the recursion depth depends on how balanced the partitions are, since that is the source of both the best and worst cases. Third, watch the code structure — the videos below use Python and Java, so plan to translate the same recursive structure into JavaScript, where array indices, swaps, and recursive calls work much the same way.
