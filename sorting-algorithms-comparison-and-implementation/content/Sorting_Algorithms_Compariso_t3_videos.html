Introduction

Insertion sort builds a sorted region at the front of an array one element at a time. On each pass it takes the next unsorted element, compares it backward against the already-sorted portion, shifts larger elements one position to the right, and drops the element into the gap. The mental model most people use is sorting a hand of playing cards: you pick up one card at a time and slide it into its correct place among the cards you already hold.

In this course, insertion sort matters for two reasons. First, it is simple enough that you can trace every comparison and shift by hand, which makes it an ideal vehicle for learning how to count operations and derive Big O bounds. Second, its performance profile is genuinely useful: it runs in linear time on nearly-sorted input, sorts in place with O(1) extra memory, and is stable, which is why real-world hybrid sorts fall back to it for small subarrays.

The videos below are taught in C++ and Java, but the algorithm is language-independent — the loop structure translates directly to JavaScript, so watch the logic and then write your own JS version. As you watch, pay attention to three things: the role of the inner while loop (shifting versus swapping), why the comparison uses a strict greater-than (this is what preserves stability), and how the number of shifts changes between already-sorted, random, and reverse-sorted input. Those observations are exactly what you need for the complexity and comparison subtopics.
