Introduction

Bubble sort is the traditional starting point for studying sorting algorithms. The idea is simple: repeatedly walk through the list, compare each pair of adjacent elements, and swap them when they are out of order. Larger values "bubble" toward the end of the array with each pass, and after enough passes the data is sorted. Because the logic is short and visual, bubble sort is an ideal place to build the habits you will need for harder algorithms: tracing nested loops, counting comparisons and swaps, and reasoning about what is guaranteed after each pass.

In this course, bubble sort serves as the baseline against which insertion sort, merge sort, and quicksort are measured. Its nested-loop structure gives O(n^2) comparisons in the average and worst cases, and an early-exit optimization (stop when a full pass produces no swaps) brings the best case down to O(n) on already-sorted input. It sorts in place with O(1) extra space and, when implemented with a strict greater-than comparison, it is stable — properties you will reuse when you compare algorithms later in the module.

The videos below use C++ and Java for their code walkthroughs, so as you watch, focus on the structure rather than the syntax: where the outer loop ends, why the inner loop shrinks on each pass, and where the swap happens. Then rewrite the same logic in JavaScript using a temporary variable or array destructuring for the swap. Pay particular attention to the "swapped" flag in the optimized version and to the honest discussion of when bubble sort is a reasonable choice (tiny or nearly sorted datasets, teaching, quick prototypes) and when it clearly is not (anything large).
